# DeskGrid 1.0.0

面向 Windows 10/11 x64 的桌面整理工具。

- 起始窗口、应用窗口和文件夹窗口，布局与设置自动保存。
- 桌面窗口吸附对齐、折叠动画、图钉锁定和自定义外观。
- 应用文件夹、入口排序、跨窗口整理与清晰的程序图标。
- Win+A 临时前置窗口，支持录制自定义快捷键。
- 目录自动刷新、列表内新建、拖动移动/复制、同名替换确认与失败气泡。
- DeskGrid 新名称及原创 EXE、浅色/深色托盘图标，兼容旧版配置。

## 使用

完整解压 `DeskGrid-windows-amd64.zip`，运行其中的 `DeskGrid.exe`。需要 WebView2 Runtime。更新前请先从托盘退出旧版本。

## 当前验证范围

应用已通过 TypeScript 检查、Vite 与 Windows amd64 Go 编译，EXE 图标和产品属性已静态检查。本次整理没有运行程序或测试；实际桌面交互和文件操作仍需在使用时确认。完整变更记录见仓库的 `bugfix.md`。
