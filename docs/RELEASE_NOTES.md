# DeskGrid v1.0.1

修复对齐吸附、分辨率变化后的布局恢复，以及文件重命名选区问题。

## 修复内容

- **吸附后可以正常拖离**：吸附范围从 8 DIP 调整为 4 DIP，依据累计鼠标位移计算自由位置，避免小幅移动反复被拉回对齐线。
- **恢复分辨率后恢复布局**：分辨率降低时临时避让，自动挪位不覆盖保存的位置和大小；分辨率恢复后复位。若主动重新摆放或缩放，则保存主动更改的部分。折叠/展开、Win+A 返回桌面及较小分辨率下重启也保留布局。
- **重命名保留扩展名**：普通文件默认只选中文件名主体，保留最后一个扩展名；目录、无扩展名文件及 `.gitignore` 这类名称完整选中。

旧版已经覆盖且没有备份的历史位置无法推算，需要先重新摆放一次；新版将保留之后保存的布局。

## 更新方式

1. 从托盘退出旧版 DeskGrid。
2. 完整解压 `DeskGrid-windows-amd64.zip`，运行其中的 `DeskGrid.exe`。

支持 Windows 10/11 x64，需要 Microsoft Edge WebView2 Runtime。已有配置继续兼容读取。

## 校验与验证范围

发布附件包含 Windows ZIP 与 `SHA256SUMS.txt`。EXE、安装信息和前端包版本已同步为 1.0.1。

本版完成 TypeScript 检查、Vite 与 Windows amd64 Go 编译，并核对发布包中的程序和校验值。按当前协作约定没有启动程序、切换分辨率、执行文件重命名或运行测试，实际交互由用户使用时确认。
