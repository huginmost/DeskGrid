# DeskGrid v1.0.2

移除窗口吸附及对齐参考线，窗口恢复自由拖动。

## 更新内容

- 删除窗口间的自动吸附、邻近窗口对齐计算、拖动基准修正及参考线原生窗口，桌面与 Win+A 前置状态均使用自由拖动。
- 保留用户主动移动/缩放后的布局保存、固定窗口的位置与大小保护。
- 保留分辨率变化后的布局恢复，以及重命名文件时仅选中文件名主体的行为。
- EXE、安装信息和前端包版本同步更新。

## 更新方式

1. 从托盘退出旧版 DeskGrid。
2. 完整解压 `DeskGrid-windows-amd64.zip`，运行其中的 `DeskGrid.exe`。

支持 Windows 10/11 x64，需要 Microsoft Edge WebView2 Runtime。已有配置继续兼容读取。

## 校验与验证范围

发布附件包含 Windows ZIP 与 `SHA256SUMS.txt`。EXE 版本为 1.0.2.0，安装信息和前端包版本为 1.0.2。

本版完成 TypeScript 检查、Vite 与 Windows amd64 Go 编译，并核对发布包中的程序和校验值。按当前协作约定没有启动程序、切换分辨率、执行文件重命名或运行测试，实际交互由用户使用时确认。
