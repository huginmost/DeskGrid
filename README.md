## DeskGrid 能做什么

DeskGrid 是一款 Windows 桌面整理工具。你可以在桌面上放置多个小窗口，分别收纳常用应用、文件和文件夹，也可以直接浏览某个目录。窗口的位置、大小、内容与外观会自动保存，下次打开时恢复布局。

- **按用途整理桌面**：为工作、游戏、设计或学习建立独立的应用窗口。
- **快速打开应用和文件**：起始窗口、应用窗口中的入口单击即可打开；快捷方式使用目标程序本体图标。
- **把常用目录留在桌面**：文件夹窗口支持目录浏览、新建、重命名、复制、移动与回收站删除，内容自动刷新。
- **自由排列窗口**：拖动标题栏自由摆放窗口；点击标题栏可折叠，固定后锁定位置、大小与折叠状态。分辨率缩小时临时避让，恢复后回到原布局。
- **自定义外观**：调整背景、透明度、文字及标题颜色、文件夹颜色、圆角和图标大小；应用窗口可以只显示图标。
- **随时临时前置**：按 `Win+A` 将桌面窗口带到其他应用前面，再按一次或点击外部即可收回；快捷键支持自行录制。

## 下载与启动

1. 前往 [Releases](https://github.com/huginmost/DeskGrid/releases)，下载 Windows 64 位的 `DeskGrid-windows-amd64.zip`。
2. 将压缩包完整解压到一个固定目录。
3. 双击解压目录中的 `DeskGrid.exe` 即可使用。

需要 **Windows 10/11 x64** 和 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。若启动时提示缺少 WebView2，请安装后重新打开。

更新版本前，先从托盘退出正在运行的旧版，再解压、运行新版。日常使用无需编译源码。

## 第一次使用

### 选择适合的窗口

| 窗口 | 用途 |
| --- | --- |
| 起始窗口 | 浏览电脑磁盘，作为访问文件和创建文件夹窗口的入口。可在全局设置中隐藏。 |
| 应用窗口 | 收纳应用、文件和文件夹的快捷入口，可切换图标或列表视图。 |
| 文件夹窗口 | 直接浏览一个磁盘目录，适合将常用项目或资料目录放在桌面上。 |

从托盘或窗口右键菜单新建窗口，再把常用应用、快捷方式、文件或文件夹拖入应用窗口。入口可以排序，也可以组成应用文件夹。

### 整理入口

- 把入口拖到另一个入口的**中心**可组成应用文件夹；拖到图标间的**间隙或边缘**可调整顺序。
- 点击应用文件夹打开它，点击顶部名称即可改名；把里面的入口拖回主窗口或其他应用窗口即可移出。
- 取消固定入口、关闭应用窗口，只移除 DeskGrid 中的整理内容，保留磁盘上的原文件。

### 浏览和管理文件

文件夹窗口中，单击选中，双击打开；左侧箭头用于展开目录树，标题栏左箭头用于返回允许范围内的上级目录。文件重命名时默认只选中文件名主体，保留最后一个扩展名；文件夹和无扩展名文件选中完整名称。新建文件或文件夹时，直接在列表中输入名称，按 `Enter` 保存、`Esc` 取消。

向磁盘目录拖入文件时，默认**移动**，按住 `Ctrl` 则复制。同名目标会提示是否替换；失败时用气泡说明原因。普通移动可在本次运行中按 `Ctrl+Z` 撤销；替换、复制和回收站删除不属于该撤销记录。“移动到回收站”会作用于磁盘文件。

### 调整布局与外观

拖动标题栏移动窗口，拖动边缘调整大小。单击标题栏折叠或展开；将鼠标移到标题栏可显示固定、关闭等按钮。固定窗口后，取消固定即可继续调整。

改变显示器分辨率时，窗口会临时适应当前工作区，恢复分辨率后按保存的布局复位。若在较小分辨率下主动移动或缩放，则以主动更改的部分为准；自动避让、折叠动画不会覆盖原来的位置和大小。

在右键菜单或托盘中打开设置：全局设置用于统一外观及快捷键，窗口设置用于单独调整当前窗口。更改会自动保存。起始窗口可通过「全局 → 隐藏起始窗口」隐藏，之后仍可恢复。

## 常用操作

| 操作 | 方式 |
| --- | --- |
| 临时前置全部桌面窗口 | `Win+A`，可在全局设置中录制其他组合 |
| 显示或隐藏桌面窗口 | 默认 `Ctrl+Alt+S` |
| 显示窗口 | 单击托盘图标 |
| 文件夹返回 / 前进 / 上级 | `Alt+←` / `Alt+→` / `Alt+↑` |
| 手动刷新目录 | `F5`，平时自动刷新 |
| 撤销普通文件移动 | `Ctrl+Z` |
| 完全退出程序 | 托盘右键 → 退出 DeskGrid |

`Win+A` 与 Windows 系统快捷键重合，如果希望保留系统原来的行为，可以在 DeskGrid 设置中更换或清除该快捷键。

## 设置保存在哪里

新用户的配置默认保存在 `%APPDATA%\DeskGrid`，包括窗口布局、外观和固定入口。备份该目录即可保留设置。

从 Sticker 升级时，如果已有 `%APPDATA%\sticker` 且没有新目录，DeskGrid 会继续读取旧目录，保留原有布局。退出程序会保留窗口；关闭某个可关闭的窗口会删除该窗口的定义。
